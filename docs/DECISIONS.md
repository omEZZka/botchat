# Решения

Зафиксированные варианты там, где ТЗ допускало толкование.

1. **Онбординг и OpenCode Zen.** Без ключа доступен `opencode` (бесплатные модели),
   поэтому первый ответ возможен до ввода ключа. Ключ добавляется в онбординге на шаге 2.
2. **Bash и rootfs.** Rootfs — отдельный артефакт (`scripts/build-runtime.sh`).
   Без него `bash` честно отвечает «rootfs не установлен», остальные инструменты работают.
   В релизный workflow артефакт подключается отдельным файлом, чтобы APK не раздувался.
3. **Чекпоинты.** Вместо внешнего git — shadow-снимки файлов внутри `.checkpoints`
   папки чата. Это даёт атомарность и отсутствие зависимости от бинарника git.
4. **Субагент.** `task` выполняет один запрос без инструментов. Это предсказуемо,
   не блокирует родителя и укладывается в лимиты мобильного времени.
5. **Разрешения.** `bash`, `write`, `edit`, `webfetch` спрашивают всегда, кроме
   режима «Доверять агенту в этом чате» (флаг `autoApprove=always` или `trustChats`).
   Запись внутри папки чата не является «вне проекта»: вне проекта путь просто отклоняется.
6. **Папка проекта.** `projectFolder` — относительный путь внутри папки чата.
   Абсолютные пути вне песочницы запрещены на уровне `canonicalPath`.
7. **Ключи.** Несколько ключей на провайдера, активный помечен. AES-GCM + Android Keystore,
   в UI только маска `sk-…abcd`. Из экспорта и бэкапа исключены полностью.
8. **Модели.** Кеш `/models` в `files/models.json`. Для `opencode` есть встроенный список,
   если сеть недоступна.
9. **Fallback.** Сначала следующий ключ того же провайдера (при 429 — ещё и ротация
   активного), затем смена модели из `fallbackChain`.
10. **Темы.** Тёмная по умолчанию; светлая + 3 акцента (синий, зелёный, фиолетовый) через CSS-переменные.
11. **Эмодзи.** Запрещены; иконки — только `js/icons.js`.
12. **Локаль.** RU по умолчанию, EN — на этапе 10.
13. **CI.** `versionCode = 1000 + run_number`, `versionName = 1.0.<run_number>`,
    релиз `build-<run_number>` с подписанным APK.
14. **Хранение состояния агента.** `steps.jsonl` пишется в папку чата; после перезапуска
    процесса UI восстанавливает историю из IndexedDB, а шаги — из файла.
